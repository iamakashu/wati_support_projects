# Project Management Hub

This repository centralizes our team's project management – combining AI-powered skills with real‑time project tracking.

## What's Inside

| Path                 | Purpose                                                                                                            |
| :------------------- | :----------------------------------------------------------------------------------------------------------------- |
| `/skills/`           | AI skills (Claude Code compatible) for automating PM tasks: status reports, risk detection, sprint summaries, etc. |
| `/projects/`         | One folder per active project, containing charter, timeline, requirements, and progress notes.                     |

## How to Use

### For team members (human)
- Browse `/projects/` to check any project's current status, owner, and next milestones.
- Review `/reports/weekly/` for the latest team progress.
- Use templates in `/templates/` to create consistent project artifacts.
